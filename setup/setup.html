Rift needs Accessibility

To type your dictated text and use global shortcuts, Rift needs Accessibility permission.

  • Allows Rift to paste text where you're typing
  • Enables global keyboard shortcuts (⌃1, ⌃2, ⌃3)
  • Required by macOS for all dictation apps
